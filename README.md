# Furusato

**Furusato** — клиентский CoreMod для Minecraft Forge 1.12.2. Его цель —
аккуратно переносить в старую версию современные возможности интерфейса и
доступности, сохраняя ванильный стиль и совместимость с другими модами.

- Название мода: `Furusato`
- Mod ID: `furusato`
- Автор: `DemonicRous`

## Требования

- JDK 8
- Minecraft 1.12.2
- Minecraft Forge 14.23.5.2847 или новее для 1.12.2

## Сборка

```powershell
.\gradlew.bat build
```

Готовый JAR создаётся в `build/libs`.

## Установка

1. Установите Minecraft Forge 1.12.2.
2. Поместите `Furusato-<версия>.jar` в папку `mods` игрового экземпляра.
3. Убедитесь, что одновременно не установлены старые сборки Lime Core или
   Furusato.

## Возможности

- Сохраняет выбранный нечётный масштаб интерфейса при использовании
  Unicode-шрифта. Например, масштаб 3 больше не уменьшается до 2 при выборе
  русского языка.
- Загружает настройки CoreMod до инициализации обычных Forge-модов.
- Безопасно отказывается от ASM-патча, если структура целевого класса не
  соответствует ожидаемой Minecraft 1.12.2.
- Выводит итоговое состояние bytecode-патчей в журнал запуска.
- Добавляет хаб с категориями «Основные настройки», «Шрифт и масштаб
  интерфейса» и «Диагностика и совместимость».
- Добавляет экран настройки шрифта, также доступный из настроек графики.
- Предоставляет четыре понятных уровня масштаба: «Маленький», «Средний»,
  «Большой» и «Авто», а также показывает фактически применённый масштаб.
- Позволяет переключать принудительный Unicode-шрифт и Unicode GUI Scale patch
  через графический интерфейс.
- Показывает среду, Unicode-ресурсы, патч, safe mode и сторонние трансформеры на
  вкладках диагностического экрана.
- Объясняет обнаруженные проблемы и предлагает действия для их устранения.
- Формирует безопасный диагностический отчёт: его можно скопировать или
  сохранить без перезаписи в папку `furusato-reports`.
- Позволяет открыть папку отчётов непосредственно из игры.
- Атомарно сохраняет конфигурацию, создаёт `furusato.properties.bak` и не
  удаляет неизвестные параметры будущих версий.
- Различает настроенное и реально активное состояние раннего патча и сообщает,
  когда необходим перезапуск Minecraft (начиная с разрабатываемой 0.8.0).

План следующих версий: [docs/ROADMAP.md](docs/ROADMAP.md).

## Конфигурация

После первого запуска создаётся `config/furusato.properties`:

```properties
patches.unicodeGuiScale=true
diagnostics.logging=true
```

- `patches.unicodeGuiScale` включает сохранение нечётного масштаба интерфейса.
- `diagnostics.logging` включает сводку о состоянии патчей в журнале.

Настройки читаются ранним загрузчиком CoreMod, поэтому применяются уже при
следующем запуске Minecraft.

`patches.unicodeGuiScale` требует перезапуска. `diagnostics.logging`
применяется при последующих диагностических событиях без перезапуска.

## Безопасный режим

Safe mode запускает Furusato без собственного ASM-патча. Он нужен для проверки
совместимости и восстановления запуска после возможного конфликта CoreMod.

При обычном запуске Minecraft добавьте JVM-аргумент:

```text
-Dfurusato.safeMode=true
```

При запуске среды разработки через Gradle используйте:

```powershell
.\gradlew.bat runClient -PfurusatoSafeMode=true
```

Safe mode задаётся только до запуска и не переключается из игрового меню.

## Разработка

Для запуска клиента нужен JDK 8:

```powershell
$env:JAVA_HOME = "C:\Program Files\Eclipse Adoptium\jdk-8.0.432.6-hotspot"
$env:Path = "$env:JAVA_HOME\bin;$env:Path"
.\gradlew.bat runClient
```

Проверка и сборка:

```powershell
.\gradlew.bat clean build
```
