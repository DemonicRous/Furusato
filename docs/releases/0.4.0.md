# Furusato 0.4.0

Версия 0.4.0 развивает конфигурационный хаб и добавляет встроенную диагностику
CoreMod без необходимости вручную искать сведения в журнале запуска.

## Диагностика и совместимость

Новая категория открывается через:

```text
Главное меню → Mods → Furusato → Config → Диагностика и совместимость
```

Экран показывает:

- версии Furusato, Minecraft и Forge;
- итоговое состояние Unicode GUI Scale patch;
- активность стандартного Unicode-шрифта Minecraft;
- выбранный и фактически применённый масштаб интерфейса;
- доступность таблицы размеров и Unicode-страницы шрифта;
- относительный путь к конфигурации Furusato;
- итоговое состояние с цветовым выделением предупреждений.

Информация размещается в адаптивной центральной карточке. На широких экранах
её ширина ограничена, поэтому названия и значения не разъезжаются к краям; на
небольших окнах карточка использует доступное пространство. Строка под
указателем мыши получает ненавязчивую подсветку без ступенчатой анимации. Текст
визуально центрируется по высоте с поправкой на метрики Unicode-глифов. Фон и
фиолетовая градиентная рамка карточки совпадают со стилем игровых tooltip.

Состояния патча `APPLIED`, `DISABLED`, `SKIPPED`, `FAILED` и ожидание применения
переведены на русский и английский языки.

## Диагностический отчёт

Кнопка «Копировать отчёт» помещает в буфер обмена компактную техническую
сводку. Она содержит детали ASM-патча и основные настройки, но не раскрывает
абсолютный путь, имя пользователя или другие лишние данные локальной системы.

## Внутренние изменения

- `PatchDiagnostics` предоставляет синхронизированный read-only снимок
  состояния патчей для клиентского интерфейса.
- Ранний конфиг предоставляет фактически загруженный файл без повторного
  чтения с диска.
- Добавлен тест, подтверждающий независимость диагностических снимков.

## Проверка

```powershell
.\gradlew.bat clean build
```

Результат:
