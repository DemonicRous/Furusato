# Furusato 0.8.0

Версия 0.8.0 делает состояние ранних настроек однозначным: интерфейс больше не
показывает сохранённое значение как уже применённое до перезапуска Minecraft.

## Новое

- Furusato отдельно хранит настроенное и активное состояние Unicode GUI Scale
  patch.
- Хаб отмечает категорию шрифта символом перезапуска, если изменение ожидает
  применения.
- Экран шрифта сохраняет простую подпись настройки, а при ожидающем изменении
  отдельно показывает переход текущего значения в новое после перезапуска.
- В основных настройках можно отменить отложенное изменение без ручного
  редактирования файла.
- Диагностика и экспортируемый отчёт содержат настроенное, активное состояние и
  признак ожидающего перезапуска.

## Надёжность

- Активное значение фиксируется во время ранней загрузки CoreMod и не меняется
  от действий в GUI.
- Добавлены тесты перехода в ожидающее состояние и его отмены.
