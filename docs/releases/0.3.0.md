# Furusato 0.3.0

Версия 0.3.0 добавляет графический интерфейс управления шрифтом и масштабом,
приближая настройки Minecraft 1.12.2 к новым версиям игры.

## Переименование проекта

Начиная с версии 0.3.0 проект называется Furusato. Изменены:

- название мода и JAR;
- `modid`: `limecore` → `furusato`;
- Java package: `com.demonicrous.limecore` → `com.demonicrous.furusato`;
- namespace ресурсов: `assets/limecore` → `assets/furusato`;
- конфигурация: `limecore.properties` → `furusato.properties`;
- репозиторий и локальные каталоги проекта.

Если при первом запуске Furusato обнаруживает старый
`config/limecore.properties`, его содержимое автоматически копируется в
`config/furusato.properties`. Старый файл сохраняется как резервная копия.

## Font Settings

Новый экран доступен двумя способами:

```text
Главное меню → Mods → Furusato → Config → Font and GUI Scale
Главное меню → Options → Video Settings → Font Settings
```

Экран переведён на русский и английский языки и содержит:

- выбор масштаба интерфейса;
- отображение фактически применённого масштаба;
- переключатель принудительного Unicode-шрифта;
- переключатель сохранения нечётного Unicode-масштаба;
- предпросмотр английского и русского текста;
- напоминание о перезапуске после изменения раннего патча.

Подписи настроек сделаны компактными и остаются внутри кнопок даже при крупном
Unicode-шрифте. При наведении отображается поясняющий tooltip; его переносы
строк вычисляются один раз при открытии экрана, чтобы не создавать лишнюю
нагрузку при движении мыши. Длинное напоминание о перезапуске автоматически
переносится по ширине экрана.

## Расширенный GUI Scale

Стандартный экран Minecraft 1.12.2 циклически переключает только четыре
состояния GUI Scale. Furusato предоставляет следующие значения:

```text
Маленький, Средний, Большой, Авто
```

Выбранное значение сохраняется в стандартном `options.txt`. Minecraft всё ещё
ограничивает фактический масштаб минимальным размером интерфейса 320×240.
Режим Auto самостоятельно выбирает максимальное допустимое значение для
текущего размера окна.

Изменение масштаба немедленно пересчитывает размеры текущего интерфейса и
перестраивает Font Settings без перезапуска клиента.

## Force Unicode Font

Переключатель управляет стандартным параметром Minecraft
`forceUnicodeFont`. Изменение сразу обновляет `FontRenderer` и сохраняется в
`options.txt`.

## Unicode GUI Scale patch

Параметр `patches.unicodeGuiScale` теперь можно менять из Font Settings. Новое
значение записывается в:

```text
config/furusato.properties
```

Поскольку трансформер применяется при загрузке класса `ScaledResolution`, после
изменения этой настройки необходим полный перезапуск Minecraft.

## Интеграция с Forge GUI

Furusato регистрирует собственный `IModGuiFactory`, поэтому кнопка Config в
списке Forge-модов открывает хаб категорий. В 0.3.0 в нём доступна категория
Font and GUI Scale; следующие группы настроек можно добавлять, не меняя точку
входа. Дополнительно обработчик `GuiScreenEvent` разделяет нижнюю строку Video
Settings на кнопки Font и Done без дополнительного ASM-патча.

## Локализация

Добавлены:

```text
assets/furusato/lang/en_us.lang
assets/furusato/lang/ru_ru.lang
```

## Тестирование

Автоматически проверяются:

- цикл значений Auto → 1…8 → Auto;
- обратный переход Auto → 8;
- нормализация повреждённых значений;
- сохранение Unicode GUI Scale patch из графического интерфейса;
- повторная загрузка сохранённого раннего конфига;
- все тесты ASM и конфигурации из версии 0.2.0.

Сборка выполняется на JDK 8:

```powershell
.\gradlew.bat clean build
```

Результат:

```text
build/libs/Furusato-0.3.0.jar
build/libs/Furusato-0.3.0-sources.jar
```

## Обновление с 0.2.0

1. Удалите старый `LimeCore-0.2.0.jar` и установите `Furusato-0.3.0.jar`.
2. Старый `config/limecore.properties` будет автоматически перенесён в
   `config/furusato.properties`.
3. Откройте Font Settings через список модов или Video Settings.
4. После изменения Unicode GUI Scale patch полностью перезапустите клиент.

Миграция миров и ресурсов не требуется.
