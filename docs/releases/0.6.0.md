# Furusato 0.6.0

Версия 0.6.0 добавляет полноценное управление основной конфигурацией и
разделяет диагностическую информацию на тематические категории.

## Основные настройки

В конфигурационном хабе появилась третья категория:

```text
Главное меню → Mods → Furusato → Config → Основные настройки
```

Экран позволяет:

- включать и выключать `diagnostics.logging`;
- видеть состояние JVM-only safe mode;
- восстановить известные параметры по умолчанию после отдельного
  подтверждения;
- увидеть успешный или неудачный результат сохранения;
- получить предупреждение о перезапуске, если сброс изменил ранний ASM-патч.

Safe mode отображается как read-only, поскольку его значение определяется до
загрузки конфигурации JVM-параметром `-Dfurusato.safeMode=true`.

## Надёжное сохранение

Каждый параметр имеет единое внутреннее описание: ключ, значение по умолчанию
и признак необходимости перезапуска. При изменении Furusato:

1. создаёт обновлённую копию свойств;
2. полностью записывает `furusato.properties.tmp` в UTF-8;
3. сохраняет предыдущий конфиг в `furusato.properties.bak`;
4. атомарно заменяет основной файл или использует безопасный fallback, если
   файловая система не поддерживает atomic move;
5. удаляет временный файл даже после ошибки.

Неизвестные ключи не удаляются при изменении или сбросе, что обеспечивает
прямую совместимость с будущими версиями Furusato.

## Категории диагностики

Параметры распределены по трём вкладкам:

- «Обзор»: версия Furusato, среда Minecraft/Forge, конфигурация и итог;
- «Графика»: Unicode-патч, Unicode-шрифт, GUI Scale и ресурсы;
- «Совместимость»: safe mode и количество сторонних трансформеров.

Кнопки копирования и экспорта продолжают формировать полный отчёт независимо
от открытой вкладки.

## Проверка

- атомарное сохранение и удаление временного файла;
- создание резервной копии;
- сохранение неизвестных ключей при изменении и сбросе;
- восстановление известных значений по умолчанию;
- все тесты ASM, safe mode, диагностики и GUI Scale предыдущих версий.

```powershell
.\gradlew.bat clean build
```
