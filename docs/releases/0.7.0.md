# Furusato 0.7.0

Версия 0.7.0 развивает встроенную диагностику и упрощает подготовку отчёта
для поиска конфликтов CoreMod.

## Новое

- Добавлена вкладка «Проблемы» с конкретными причинами предупреждений и
  рекомендациями по их устранению.
- Диагностические отчёты сохраняются в отдельную папку `furusato-reports`.
- Имя каждого отчёта содержит дату и время, поэтому предыдущие отчёты не
  перезаписываются.
- Добавлена кнопка открытия папки с отчётами из игры.
- Полные значения, не помещающиеся в строку диагностики, доступны во всплывающей
  подсказке.

## Надёжность

- Открытие папки проверяет поддержку системного Desktop API и корректно сообщает
  об ошибке вместо падения игры.
- Логика определения проблем отделена от GUI и покрыта модульными тестами.
