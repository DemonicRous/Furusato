# Furusato 0.5.0

Версия 0.5.0 посвящена безопасному восстановлению и диагностике совместимости
в крупных сборках Minecraft Forge 1.12.2.

## Безопасный режим

Furusato можно запустить без регистрации собственных ASM-трансформеров:

```text
-Dfurusato.safeMode=true
```

В среде разработки режим запускается командой:

```powershell
.\gradlew.bat runClient -Dfurusato.safeMode=true
```

Параметр проверяется до загрузки `furusato.properties` и до регистрации
`UnicodeGuiScaleTransformer`. Интерфейс, Unicode-ресурсы и диагностика остаются
доступными. Экран показывает состояние `SAFE_MODE`, а хаб отмечает категорию
диагностики префиксом `[!]`.

Для обычного запуска удалите JVM-параметр. Изменение всегда требует полного
перезапуска Minecraft.

## Совместимость

Экран диагностики читает публичный список
`LaunchClassLoader#getTransformers()` и показывает количество сторонних
трансформеров. Само наличие стороннего трансформера не считается конфликтом:
предупреждение появляется только при `SKIPPED`, `FAILED` или безопасном режиме.

Полные имена всех трансформеров и отдельный список сторонних компонентов
добавляются в технический отчёт. Furusato не изменяет и не переупорядочивает
чужие трансформеры.

## Экспорт отчёта

Помимо буфера обмена отчёт можно сохранить кнопкой «В файл»:

```text
logs/furusato-diagnostics.txt
```

Файл записывается в UTF-8 и, как и копируемый отчёт, не содержит абсолютного
пути или имени пользователя. Повторный экспорт безопасно заменяет предыдущую
сводку актуальными данными.

## Проверка

- safe mode не возвращает ни одного Furusato-трансформера;
- диагностический реестр публикует состояние `SAFE_MODE` как предупреждение;
- платформенные и собственные трансформеры отделяются от сторонних;
- стандартные ASM-, конфигурационные и GUI policy-тесты продолжают проходить.

```powershell
.\gradlew.bat clean build
```
